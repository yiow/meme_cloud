## 功能模块与目录对应关系

| 优先级 | 功能模块 | Android 目录 | Backend 目录 |
|--------|---------|-------------|-------------|
| 🔴 | AI拍照映射检索 | `ui/home/` `ui/search/` | `services/retrieval/` `ai/mobilenet/` `ai/clip/` `ai/faiss/` |
| 🔴 | 文字/图片检索 | `ui/search/` | `services/retrieval/` `ai/clip/` |
| 🔴 | 表情包管理 | `ui/profile/` | `services/user/` |
| 🔴 | 社区广场 | `ui/community/` | `services/community/` |
| 🟡 | 排行榜 | `ui/community/` | `services/community/` |
| 🟡 | 弹幕斗图室 | `ui/battle/` `data/websocket/` | `services/battle/` `core/websocket.py` |
| 🟡 | 话题挑战 | `ui/community/` | `services/community/` |
| 🟡 | 好友关注 | `ui/profile/` | `services/user/` |
| 🟡 | 表情包悬赏 | `ui/community/` | `services/user/` |

## Android 模块分层说明

```
┌─────────────────────────────────────────────────┐
│                   UI Layer                       │
│  home/  search/  community/  battle/  publish/  │
│  profile/                                       │
│  (Activity / Fragment / Composable)              │
├─────────────────────────────────────────────────┤
│                Data Layer                        │
│  api/        → Retrofit 网络接口                │
│  model/      → 数据传输对象 (DTO)               │
│  repository/ → 数据仓库模式                     │
│  websocket/  → OkHttp WebSocket                 │
├─────────────────────────────────────────────────┤
│                 DI Layer                         │
│  di/         → Hilt / Koin 依赖注入             │
├─────────────────────────────────────────────────┤
│                Util Layer                        │
│  util/       → 图片压缩 / 相机辅助 / 扩展函数   │
└─────────────────────────────────────────────────┘
```

## Backend 模块分层说明

```
┌─────────────────────────────────────────────────┐
│                 API Layer                        │
│  routes/  → 路由注册 & 请求处理                  │
│  models/  → Pydantic 请求/响应模型               │
│  schemas/ → 数据校验 Schema                      │
├─────────────────────────────────────────────────┤
│              Service Layer                       │
│  retrieval/  community/  battle/  user/          │
│  → 核心业务逻辑                                  │
├─────────────────────────────────────────────────┤
│                AI Layer                          │
│  clip/  mobilenet/  faiss/                       │
│  → 模型推理 & 特征提取 & 向量检索                │
├─────────────────────────────────────────────────┤
│                DB Layer                          │
│  db/models/       → SQLAlchemy ORM              │
│  db/migrations/   → Alembic 数据库迁移           │
├─────────────────────────────────────────────────┤
│               Core Layer                         │
│  config.py  security.py  websocket.py            │
│  → 应用配置 / JWT认证 / WebSocket管理            │
└─────────────────────────────────────────────────┘
```

## 关键技术栈

| 层级 | Android | Backend |
|------|---------|---------|
| 语言 | Kotlin | Python 3.10+ |
| 框架 | Jetpack Compose | FastAPI |
| 网络 | Retrofit + OkHttp | - |
| 实时通信 | OkHttp WebSocket | FastAPI WebSocket |
| 图片加载 | Coil / Glide | - |
| 相机 | CameraX | - |
| 依赖注入 | Hilt / Koin | - |
| ORM | - | SQLAlchemy |
| 数据库 | - | MySQL 8.0 / PostgreSQL |
| 图片存储 | - | MinIO（或本地文件系统） |
| AI推理 | - | Chinese-CLIP + MobileNetV3 + FAISS |
| 认证 | - | JWT Token |
| 测试 | JUnit + Espresso | pytest + httpx |
